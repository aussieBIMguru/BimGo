Place list (Resources\places.tsv, shipped beside BimGo.exe)

Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

The sun panel's location search uses an offline list of about 7,300 cities and
towns (name, region, country, latitude, longitude, IANA time zone, population).
How it was made:
- Source: Natural Earth 1:10m Cultural Vectors, "Populated Places"
  (ne_10m_populated_places.geojson), taken from the project's repository
  https://github.com/nvkelso/natural-earth-vector, commit ca96624
  (2022-06-02, VERSION 5.2.0-pre), downloaded 2026-10-11.
- Converted by make_places.py (in BimGo's source, ai/261011b_Video_Location):
  only the fields above are kept; names the interface font can't draw use
  Natural Earth's ASCII name; a place without a time zone in the source takes the zone of the
  nearest place in the same country that has one (same region preferred).
  No other data was added.
- Licence: Natural Earth is in the public domain ("All versions of Natural
  Earth raster + vector map data found on this website are in the public
  domain... No permission is needed to use Natural Earth. Crediting the
  authors is unnecessary." - https://www.naturalearthdata.com/about/terms-of-use/).
  No attribution is required; this credit is given anyway. Primary authors:
  Tom Patterson and Nathaniel Vaughn Kelso, with Natural Earth's contributors.
- Natural Earth notes that it is provided as a public service, without any
  responsibility for accuracy; BimGo passes the data on on the same basis.
  Place positions are city reference points: for a building, paste the
  site's own coordinates.

Not shipped with BimGo

- Autodesk Revit API (RevitAPI.dll, RevitAPIUI.dll): referenced at build time
  from the user's own Revit installation and never copied into BimGo's output.
  No Autodesk files, textures or content are included.
- Fonts: the interface draws text with fonts already installed in Windows
  (Bahnschrift, Segoe UI, Consolas; for other scripts, whichever Windows font
  has the character, such as Microsoft YaHei UI, Yu Gothic UI, Malgun Gothic or
  Nirmala UI). No font files are shipped.
- OpenGL: provided by Windows and the graphics driver; all shaders are
  BimGo's own.
- Video encoding (walkthrough video, MP4 / H.264): done by Windows Media
  Foundation and the H.264 encoder that come with Windows (or the graphics
  driver's hardware encoder). BimGo bundles no codec and no encoding library.
- Time zones and daylight saving: read at run time from Windows' own time zone
  data (IANA ids through .NET / ICU). No time zone database is shipped.
- Light profiles (IES photometric files): the IESNA LM-63 reader is
  BimGo's own code, and the five built-in profiles (narrow / medium downlight,
  wide flood, wall washer, pendant) are generated by BimGo's own formulas
  (MIT-0). No manufacturer or third-party .ies files are shipped. The .ies
  files a Revit family names, or that a user imports, are copied into that
  user's own .bimgo / model folder only; their terms stay with their makers.
  The test files in tests\ are hand-written for BimGo (CC0).

Acknowledgements: published methods and open formats

BimGo implements the methods and formats below from their published
descriptions and formulas. No third-party source code is copied. They are
acknowledged with thanks.

Sun and daylight
- Solar position: NOAA Global Monitoring Laboratory, "General Solar Position
  Calculations" (declination and equation of time). US Government work.
- Sky luminance: CIE standard overcast sky and CIE clear sky distributions
  (Commission Internationale de l'Eclairage; ISO 15469 / CIE S 011).
- Clear-sky illuminance: IES (Illuminating Engineering Society) clear-sky
  diffuse horizontal and direct normal illuminance formulas.
- Internally reflected component: BRE (Building Research Establishment)
  split-flux formula.
- Ray directions: Hammersley point set with cosine-weighted hemisphere mapping.
- Sun hours, daylight factor and lux results are early design indicators, not
  compliance simulations.

Rendering and geometry
- Ambient occlusion: spiral sampling after M. McGuire, M. Mara, D. Luebke,
  "Scalable Ambient Obscurance" (HPG 2012); BimGo's own GLSL.
- Ray / triangle intersection: T. Moller and B. Trumbore, "Fast, Minimum
  Storage Ray-Triangle Intersection" (1997).
- Reflections: C. Schlick's Fresnel approximation (1994).
- Shadows: shadow mapping with percentage-closer filtering (W. Reeves,
  D. Salesin, R. Cook, 1987).
- Section caps: the stencil-buffer capping technique for clipping planes.

Clash detection
- Triangle / triangle intersection: T. Moller, "A Fast Triangle-Triangle
  Intersection Test" (Journal of Graphics Tools, 1997): the plane-side and
  interval-overlap test, with BimGo's own depth estimate on top.
- Closest points on a triangle and between two segments: the standard region
  and clamping formulas, as described in C. Ericson, "Real-Time Collision
  Detection" (2005), chapter 5.
- Broad phase: sweep and prune over bounding boxes (D. Baraff, 1992;
  J. Cohen, M. Lin, D. Manocha, M. Ponamgi, "I-COLLIDE", 1995), and a median-
  split bounding-volume tree per large element.
- Inside tests: the even-odd (ray parity) rule, with the Moller-Trumbore ray
  test above.
- Clash records, statuses and reports are BimGo's own JSON format.

Places and time
- Place list: Natural Earth (public domain), see "Place list" above.
- Time zone names: the IANA Time Zone Database identifiers (e.g.
  "Australia/Sydney"; the tz database is in the public domain).
- Typed coordinates: decimal degrees and degrees / minutes / seconds, read by
  BimGo's own parser; distances by the haversine formula.

Windows interfaces
- Media Foundation sink writer (MFCreateSinkWriterFromURL, IMFSinkWriter,
  IMFSample, IMFMediaBuffer, IMFAttributes) called from BimGo's own interop
  code, following Microsoft's published Windows SDK documentation. The GUID
  values and interface method order (facts needed to call Windows, defined by
  Microsoft) were cross-checked against the mingw-w64 project's headers
  (mfapi.h, mfobjects.idl, mfreadwrite.idl; https://github.com/mingw-w64/mingw-w64,
  Zope Public License 2.1). No mingw-w64 code or files are copied into or
  shipped with BimGo; they are acknowledged with thanks.

File formats
- BCF 2.1 (BCF-XML), buildingSMART International: comment import / export.
- IFC GUID compressed 22-character encoding, buildingSMART International.
- Google Photo Sphere XMP metadata (GPano) for 360-degree panoramas.
- PNG and JPEG via the .NET / Windows imaging components.
- MP4 (ISO base media file format) with H.264 / AVC video, written by Windows
  Media Foundation.

Entourage billboards

The built-in billboards (trees, shrubs, people, cars) are drawn in code by
BimGo itself (BimGo.Core EntourageArt) and are part of BimGo under MIT-0; no
third-party pictures are bundled. Traced silhouettes (EntourageShapes) will be
Gavin's own drawings (Aussie BIM Guru, MIT-0), each credited in its entry.
Pictures a user imports (IMPORT PNG / IMPORT FOLDER) stay under their own
licence: BimGo never ships them, but a .bimgo the user saves carries them, so
sharing that file is subject to the pack's terms.
